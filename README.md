# Lalaina Ratsirarisona - Developer Portfolio

Welcome to the source code of my personal developer portfolio! This project is a modern, highly interactive, and visually stunning web application built to showcase my skills, experiences, and projects as a Full-Stack Web & Desktop Developer.

## ✨ Key Features

- **Deep Tech Aesthetic**: A sleek, dark-themed UI (Cobalt Blue and Ardoise) inspired by modern cloud infrastructure and developer tools.
- **Interactive Hero Section**: Features a unique, VS Code-inspired interactive code editor modal that displays my developer profile as a JavaScript object.
- **3D Project Showcase**: An auto-scrolling marquee of project cards with 3D hover effects (powered by Framer Motion). Clicking on a project opens a detailed floating modal with deep dives into technologies and features.
- **Dynamic Skills Display**: An infinite scrolling marquee showcasing my technical stack with crisp SVG icons.
- **Fully Responsive**: Optimized for all screen sizes, from mobile devices to large desktop monitors.
- **Contact Form**: Integrated contact form for easy communication.

## 🛠️ Technology Stack

This portfolio is built with modern, high-performance web technologies:

- **Framework**: [Next.js](https://nextjs.org/) (React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **UI Components**: Custom-built components utilizing `clsx` and `tailwind-merge`
- **Icons**: React Icons & Custom SVGs

## 📦 Local Development

If you want to run this project locally, follow these steps:

### Prerequisites
- Node.js (v18 or higher recommended)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 📁 Project Structure Highlights

- `/app`: Contains the Next.js App Router pages and layouts.
- `/app/components`: Reusable UI components (Hero, Projects, Skills, etc.).
- `/utils/data`: Data files (`projects-data.js`, `skills.js`, `experience.js`, etc.) making it easy to update the portfolio content without touching the UI code.
- `/public`: Static assets like images and project screenshots.
